## 6. Condições para Piloto

O piloto RC-1 é aprovado com as seguintes condições obrigatórias:

```
□ Todas as 28 variáveis de ambiente configuradas no Vercel
□ PORTAL_JWT_SECRET obrigatoriamente configurada (não usar fallback)
□ JWT_SECRET ≥ 64 chars (aleatorio, não o valor padrão)
□ TOTP 2FA activado para conta admin principal
□ npm audit --audit-level=high: zero findings HIGH/CRITICAL
□ Smoke test manual completo (15 passos do deployment checklist)
□ Sentry activo e monitorizado
□ Runbook comunicado a pelo menos 1 pessoa da equipa além do PO
□ Backup BD manual executado nas primeiras 24h
□ Piloto limitado a Azul Coworking (1 empresa real) nas primeiras 2 semanas
```
